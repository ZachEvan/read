## 阅读分类

### 1. 高性价比人生指南（HowToLiveBetter）

- **目录**：[阅读/高性价比人生指南](./阅读/高性价比人生指南)
- **原仓库**：https://github.com/eternity4719/HowToLiveBetter
- **内容**：767 条生活建议，每条标注成本/收益/证据等级，涵盖健康、急救、省钱理财、法律红线、失业兜底、婚育、出国等 34 个主题
- **许可**：正文 CC BY 4.0，代码 MIT
- **说明**：这是一份备选清单而非任务清单，内容可能过时，办事/看病/打官司以当地部门、医生、律师说法为准

### 2. 自学是门手艺（The Craft of Selfteaching）

- **目录**：[阅读/自学是门手艺](./阅读/自学是门手艺)
- **原仓库**：https://github.com/selfteaching/the-craft-of-selfteaching
- **作者**：李笑来
- **内容**：用 Jupyter Notebook 写成的开源书，以 Python 为练习材料，讲「怎么学会学习」——自学方法、刻意练习、拆解难点、避免注意力漂移等，共 47 个 notebook + Markdown 版全文
- **许可**：CC BY-NC-ND（署名-非商业性使用-禁止演绎）
- **说明**：书的核心理念是「自学是一门手艺，无需天分，熟练程度决定一切」；书中设计了一套 PoW（工作量证明）读书法，建议 fork 后边读边 commit
